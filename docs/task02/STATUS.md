## 2. 硬件与接线

| 项目 | 型号/说明 |

| 执行器 | SG90 180° 舵机 × 2 |

| 供电 | F103 由 USB 供电；舵机由外部 5V/2A 独立供电，单点共地 |

阶段版接线：

```text
yaw   SG90 橙线 -> PA6 (TIM3_CH1)
pitch SG90 橙线 -> PA7 (TIM3_CH2)
两个舵机 红线 -> 外部 5V
两个舵机 棕线 -> 外部 GND
F103 GND      -> 外部 GND（必须共地）
F103 PA9/PA10 -> CH340 RXD/TXD（USART1，115200）
J-Link 3V/GND/DIO/CLK -> 板上 SWD 4 针
```

阶段版**没有接 MPU6050，也没有接蓝牙**；MPU 和 HC-05 的接线方案保留在任务 02 计划中，但不作为本阶段已实现内容。

## 5. 失败原因

1. **MPU 安装面积不足**：pitch 平台太小，MPU 不能完整、刚性固定；只能贴在边缘或夹缝里，受力后姿态会变。
2. **舵盘刚度不足**：塑料舵盘裁剪后变软，回差和弹性变形明显。
3. **杜邦线牵拉**：云台转动时线束拉扯平台和 MPU，产生额外力矩和位移。
4. **电源/地线干扰**：MPU 单独测试正常，接上云台和舵机后误差明显增大；怀疑舵机电流在地线/线束上耦合。

结论：**不是先怀疑算法，而是当前机械和电气装配条件不足以支撑可用闭环。** 在现有条件下继续调 PID 只会把机械问题当成控制问题。

## 6. 复现方式

```powershell
cd C:\Work\brokytask01_framework
cmake --build build-servo-both -j
# 用 J-Link 烧 build-servo-both\firmware.elf
```

上电后两轴先回中，再分别 ±30° 扫角；串口会输出 `servo both` 相关日志。

注意：

- 舵机必须外部 5V 供电，不能从 F103 的 5V 引脚直接带两个舵机。
- F103 与外部 5V 必须共地。
- 第一次测试先小角度，手边准备断电。
