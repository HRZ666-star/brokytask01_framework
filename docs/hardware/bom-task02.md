## 3. 接线

```text
MPU6500  VCC -> 3.3V, GND -> GND, SCL -> PB6, SDA -> PB7, AD0 -> GND, INT NC
Yaw     橙/黄 -> PA6 (TIM3_CH1), 红 -> 5V, 棕 -> GND
Pitch   橙/黄 -> PA7 (TIM3_CH2, 未实现), 红 -> 5V, 棕 -> GND
HC-05   TXD -> PA3, RXD -> PA2 (1k/2k 分压), VCC -> 5V, GND -> GND
CH340   TXD -> PA10, RXD -> PA9, GND -> GND
```

电源：

```text
充电头/充电宝 5V/2A
  -> USB-A 公对公
  -> 面包板电源 USB-A 母口（跳线帽两路都拨 5V）
  -> 红轨 +5V / 蓝轨 GND
  -> 舵机红/棕
F103 GND -> 蓝轨 GND（必须共地）
F103 供电仍走电脑 USB
```

## 4. 供电注意

- 电脑 USB 口通常限流 500 mA；两个 SG90 启动/堵转可能 1–1.5 A，会掉压、复位、只响不转。
- 面包板电源模块标称电流可能只有 700 mA；带载量红轨-蓝轨，低于 4.8 V 就换 5V/2A 电源。
- 舵机红线接 +5V，棕线接 GND；反接会发烫/损坏。
- 舵机信号是 3.3V PWM；多数 SG90 能识别，但少数需要 5V 逻辑。若 A6 有 PWM 且接线正确仍不转，考虑 74HCT125/三极管电平转换。
- 不要用板子 5V 直接带两个舵机。

## 6. 安全

- 舵机发烫立即断电，不要用手直接碰外壳。
- 云台上电前先确认机械限位，避免舵机顶死。
- 调试时先空载、小角度（±45°）、短时间；确认方向后再扩行程。
- 蓝牙失联/串口断流时，control 现在会把目标/输出归零；仍建议加机械限位和急停。
