# 任务 01 硬件清单（BOM）

> 这份清单只列**任务 01** 需要的硬件。  
> 任务 02 的云台支架、HC-05、舵机、外部 5V 等，见 [bom-task02.md](bom-task02.md)。

## 1. 已有

| 物品 | 数量 | 用途 | 备注 |
|---|---:|---|---|
| STM32F103C8T6 核心板 | 1 | 任务 01 主控 | 64 KB Flash / 20 KB RAM |
| STM32F407VET6 核心板 `FK407M3-VET6` | 1 | 任务 01 移植验证 | 512 KB Flash / 192 KB RAM |

| CH340 USB-TTL | 1 | 串口 | 本机 COM6 |

| 面包板电源模块 | 1 | 5V/3.3V 输出 | 任务 01 可不用；任务 02 给舵机供电 |
| TJA1050 CAN 收发器 | 1 | CAN 外部总线（可选） | 需第二节点/120Ω；当前只做 Loopback |

## 2. 任务 01 还需要/建议

### 必须补

当前没有。任务 01 的最小硬件就是：

```text
F103 + J-Link + CH340 + 面包板 + 杜邦线 + USB 供电
```

### 可选

| 物品 | 必要性 | 说明 |
|---|---|---|
| 第二块 F103/F407 | 可选 | 做 CAN 第二节点，验证外部总线 |
| 120 Ω 电阻 ×2 | 可选 | CAN 总线两端终端 |
| 逻辑分析仪 | 可选 | 看 UART/CAN/I2C/PWM 时序，比万用表直观 |

## 3. 接线

```text
J-Link   3V -> 3V3, GND -> GND, DIO -> DIO, CLK -> CLK, 5V NC
CH340    TXD -> PA10, RXD -> PA9, GND -> GND, VCC NC
BOOT0    -> GND
供电     板子 USB
```

## 4. 供电注意

- 任务 01 只用 F103 的 USB 供电，不需要外部 5V。
- 不要把舵机、电机直接接到板子 5V；任务 01 不接这些负载。
- F407 板同样用 USB 供电，J-Link 只接 `3V/GND/DIO/CLK`。

## 5. 采购参考

任务 01 当前不需要新购硬件。  
如果要做 CAN 外部总线，再补第二块板、TJA1050 和 120 Ω 终端电阻。

## 6. 安全

- 烧录前确认 `BOOT0 -> GND`，J-Link 的 `3V` 接到板子 `3V3`。
- 不要用金属物同时碰到板子 5V 和 GND。
- CAN 外部总线必须共地，两端 120 Ω。
