# MPU6050/MPU6500 测试记录

## 环境

| 项目 | 值 |
|---|---|
| 主控 | STM32F103C8T6 |
| 传感器 | GY-521 模块，实测芯片 **MPU6500**（WHO_AM_I=0x70） |
| 调试器 | J-Link v9 + Ozone |
| 串口 | CH340，COM6，115200 8N1 |
| 固件 | `build-imu/firmware.elf`，`APP=imu_test` |
| 编译 | ARM GNU 14.3，`-Os`，C++17 |
| 构建结果 | `text 25836, data 120, bss 2364` |

## 接线

| GY-521 | F103 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL | PB6 |
| SDA | PB7 |
| AD0 | GND（地址 0x68） |
| INT | 不接 |

J-Link：GND→GND、SWDIO→PA13、SWCLK→PA14、3V→3V3；CH340：TXD→PA10、RXD→PA9、GND→GND；BOOT0/BOOT1 接地。

## 测试步骤

1. 接线并上电，确认模块电源灯亮。
2. 烧录 `build-imu/firmware.elf`，复位。
3. 打开 COM6，115200 8N1，观察启动输出。
4. 记录 WHO_AM_I、异步读结果、连续三轴数据。
5. 静止放置，观察 accel Z 是否接近 1 g、gyro 是否接近 0。

## 结果

| 项目 | 结果 |
|---|---|
| I2C 阻塞读 WHO_AM_I | 通过，`0x70` |
| 芯片识别 | MPU6500，兼容路径 |
| `init()` 写配置 | 通过 |
| 异步读 `memReadAsync` | 通过，`data=FB12FFECE1B8` |
| 连续三轴数据 | 通过，9 帧稳定输出 |
| 温度 | 约 `27.2 °C`，MPU6500 公式 |
| 加速度 Z | 约 `-945 mg`（模块当前朝向使 Z 为负，不是故障） |
| 陀螺零偏 | 约 `-2.8, +2.5, +0.85 °/s`，偏大，需上电静止校准 |

## 判定

- WHO_AM_I 为 `0x68`/`0x70`/`0x71` 均接受；
- 异步读返回 `ok`；
- 连续数据不重复、不超时；
- 加速度重力方向与安装方向一致；
- 陀螺零偏在静止校准后应接近 0。

## 已知限制

- 只验证 400 kHz 阻塞读与一次中断读，未做长时间高低温/振动测试。
- 陀螺零偏未做静态校准，当前约 ±3 °/s，直接积分会漂。
- 未使用 MPU 内建 DMP，姿态解算由后续模块完成。
- 当前只支持 8 位寄存器地址。
- 该模块实际为 MPU6500，文档和答辩中不得写成“MPU6050”；驱动兼容 MPU6050/6500/9250。
