# F407 最小移植测试记录（STM32F407VET6）

这份记录只验证一件事：**同一套 BSP 接口能移植到另一块不同型号的 STM32，并跑通串口和定时器**。
不验证 FreeRTOS、I2C、CAN，也不验证外部总线。

## 1. 测试环境

| 项目 | 内容 |
|---|---|
| 日期 | 2026-11-14 |
| 主控 | FK407M3-VET6 V1.1，STM32F407VET6，512 KB Flash / 192 KB RAM |
| 串口模块 | CH340（USB-SERIAL CH340） |
| 调试器 | J-Link v9，S/N 602711527 |
| 烧录/调试 | SEGGER J-Link Commander 7.94k，SWD |
| 固件 | `build-f407/firmware.elf` |
| 板级配置 | `BOARD=f407`，`APP=f407_test` |
| 串口参数 | COM6，115200，8N1，无流控 |

> COM 号以设备管理器实际显示为准；本次为 COM6。

## 2. 接线

### 2.1 串口

| CH340 | F407 板左侧 4 针 | 说明 |
|---|---|---|
| TXD | RX | 交叉接 |
| RXD | TX | 交叉接 |
| GND | GND | 必须共地 |
| VCC | 不接 | 板子由 USB 供电 |

### 2.2 调试器

| J-Link | F407 板右侧 4 针 | 说明 |
|---|---|---|
| GND | GND | 必须共地 |
| DIO | DIO | SWDIO |
| CLK | CLK | SWCLK |
| 3V | 3V3 | **必须接**，J-Link 用它做目标电压参考 |
| 5V | 不接 | 板子由 USB 供电，避免双电源 |

### 2.3 启动与供电

| 项目 | 设置 |
|---|---|
| BOOT0 | 悬空（板内有弱下拉，从 Flash 启动） |
| BOOT1 | 悬空 |
| 供电 | 板子 USB 口 |

> 实测发现 `3V` 参考线不接时 J-Link 报 `Failed to initialized DAP`；接上后立即
> `DAP initialized successfully`。这是本次移植最容易踩的坑。

## 3. 测试步骤

1. 配置并编译 F407 镜像：

   ```powershell
   cmake -S . -B build-f407 -G Ninja `
     -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-arm-none-eabi.cmake `
     -DBOARD=f407 -DAPP=f407_test
   cmake --build build-f407
   ```

2. 用 J-Link Commander 烧录并运行：

   ```text
   device STM32F407VE
   si SWD
   speed 1000
   connect
   erase
   loadfile build-f407/firmware.elf
   r
   g
   exit
   ```

3. 打开串口监视器，选择 CH340 对应的 COM 口，设置为 115200、8N1、无流控。

4. 按一次板子 `RST`，确认启动 banner 和定时器计数。

## 4. 实测输出

```text
f407 port: boot, sysclk=168000000
f407 timer: 1000
f407 timer: 2000
f407 timer: 3000
f407 timer: 4000
```

说明：

- `sysclk=168000000` 说明 HSE 8 MHz、PLL 和 Flash latency 配置生效。
- `f407 timer` 每秒增加 1000，说明 TIM2 的 1 kHz 中断正常。
- 串口每秒输出一行，说明 USART1 的 115200 8N1 链路正常。

## 5. 结果

| 检查项 | 结果 |
|---|---|
| J-Link 能识别 Cortex-M4 | 通过 |
| 固件能擦除、下载、校验 | 通过 |
| 系统时钟 168 MHz | 通过 |
| USART1 115200 输出 | 通过 |
| TIM2 1 kHz 中断 | 通过 |

## 6. 已知限制

- 本镜像只验证 UART + TIM2，没有链接 FreeRTOS。
- F407 的 I2C/CAN 适配尚未加入，`bsp/stm32` 在 F407 下只编译 UART。
- 没有做长时间运行、复位一致性、电源波动测试。
- `3V` 参考线必须接；只接 GND/DIO/CLK 会连不上。
