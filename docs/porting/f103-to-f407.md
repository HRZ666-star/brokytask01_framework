# 从 F103 移植到 F407

目标：在另一块不同型号的 STM32（STM32F407VET6）上跑通 **串口 + 一个定时器**，验证分层边界确实可移植。

## 1. 硬件

板卡：`FK407M3-VET6 V1.1`，STM32F407VET6，512 KB Flash / 192 KB RAM，8 MHz HSE。

| 功能 | 板子引脚 | 接到 |
|---|---|---|
| SWD | `3V3 / GND / DIO / CLK` | J-Link `3V / GND / SWDIO / SWCLK` |
| UART | `TX / RX` | CH340 `RX / TX` |
| 供电 | USB | 电脑 USB |
| BOOT | `BOOT0/BOOT1` | GND |

**关键坑**：J-Link 的 `3V` 必须接到板子 `3V3`。只接 GND/DIO/CLK 时 J-Link 报：

```text
Error: Failed to initialized DAP.
Can not attach to CPU. Trying connect under reset.
```

接上 3V 参考后：

```text
DAP initialized successfully
Cortex-M4 r0p1, SW-DP ID 0x2BA01477
```

`5V` 始终不接。

## 2. 时钟

```text
HSE = 8 MHz
PLLM = 8, PLLN = 336, PLLP = 2, PLLQ = 7
SYSCLK = 168 MHz
AHB  = /1 = 168 MHz
APB1 = /4 = 42 MHz
APB2 = /2 = 84 MHz
Flash latency = 5 WS
```

注意：

- F407 **没有** `HAL_PWREx_ActivateOverDrive()`；这是 F42x/F43x 的 API。首次编译报：

```text
HAL_PWREx_EnableOverDrive was not declared
```

删除该调用即可。
- 开 FPU：`-mfpu=fpv4-sp-d16 -mfloat-abi=hard`，否则浮点会走软件库。
- `_estack = 0x20020000`（128 KB SRAM 顶部），链接脚本见 `board/f407/linker.ld`。

## 3. 需要新增/修改的文件

```text
third_party/stm32f4/            F4 HAL + CMSIS（从 Cube FW_F4 复制）
board/f407/
  board.cpp                     时钟、GPIO、USART1、TIM2
  stm32f4xx_it.cpp              中断向量
  system_stm32f4xx.c
  startup_stm32f407xx.s
  linker.ld
  inc/board.h
  inc/board_uart.h
  inc/stm32f4xx_hal_conf.h
app/f407_test.cpp               最小验证入口
```

CMake：

- `third_party/CMakeLists.txt` 按 `BOARD` 选 `stm32f1` 或 `stm32f4`。
- 根 `CMakeLists.txt` 按 `BOARD` 选：
  - `CPU_FLAGS`：F103 `-mcpu=cortex-m3`；F407 `-mcpu=cortex-m4 -mfpu=fpv4-sp-d16 -mfloat-abi=hard`
  - `HAL_TARGET`：`stm32f1_hal` / `stm32f4_hal`
  - `BOARD_SOURCES`：对应 board 源文件
- F407 最小移植先不编译 `bsp/stm32/can/hal_can.cpp`（它直接 include `stm32f1xx_hal.h`）。

## 4. 外设配置

### USART1

```text
PA9  = USART1_TX, AF7
PA10 = USART1_RX, AF7
115200 8N1, 无流控
```

### TIM2

```text
TIM2 clock = 84 MHz
PSC = 84 - 1
ARR = 1000 - 1
更新频率 = 1 kHz
```

中断里 `HAL_TIM_PeriodElapsedCallback` 给 `g_timer_ticks` 加一；`app/f407_test.cpp` 每秒打印一次。

## 5. 构建与烧录

```bash
cmake -S . -B build-f407 -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-arm-none-eabi.cmake \
  -DBOARD=f407 -DAPP=f407_test
cmake --build build-f407
```

J-Link Commander：

```text
device STM32F407VE
si SWD
speed 1000
connect
erase
loadfile build-f407/firmware.elf
r
g
```

或 Ozone：Device `STM32F407VE`，SWD 1000 kHz，打开 `build-f407/firmware.elf`，Download & Reset。

## 6. 验证

串口 115200：

```text
f407 port: boot, sysclk=168000000
f407 timer: 1000
f407 timer: 2000
f407 timer: 3000
f407 timer: 4000
```

结论：

- 168 MHz 时钟配置正确；
- USART1 输出正常；
- TIM2 1 kHz 中断正常；
- `board/f407` 与 `board/f103` 通过同一套 `IUart` 接口工作，app 代码不需要改串口调用。

## 7. 还没做的部分

- F407 的 I2C/CAN 适配器：当前 `bsp/stm32/i2c`、`bsp/stm32/can` 仍是 F1-only。
- F407 多 UART 分发：`HalUart::active_` 是单实例，多串口需要“handle → 实例”表。
- F407 FreeRTOS 六任务：当前只验证裸机 UART+TIM2；FreeRTOS port 需换 `ARM_CM4F` 并重新配 `FreeRTOSConfig.h`。
- F407 的 CAN 时钟/引脚与 F1 不同，不能直接复用 `__HAL_AFIO_REMAP_CAN1_2()`。
