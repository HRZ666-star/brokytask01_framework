# MPU6050/MPU6500/MPU9250 模块说明

## 位置

```text
modules/imu/mpu6050.h/.cpp
        ↓ 只依赖 bsp::II2c
bsp/interface/i2c/i2c.h
```

模块层不包含 HAL，也不关心 I2C 是阻塞还是中断；换到 F407 时只要 `board_i2c()` 注入另一个 `II2c` 实例。

## 默认配置

| 项目 | 值 |
|---|---|
| 7 位地址 | `0x68`（AD0 接 GND） |
| 支持芯片 | MPU6050 (`0x68`)、MPU6500 (`0x70`)、MPU9250 (`0x71`) |
| 采样率 | 200 Hz（1 kHz / (1 + SMPLRT_DIV=4)） |
| 数字低通 | DLPF 44 Hz（CONFIG=0x03） |
| 陀螺量程 | ±500 °/s（GYRO_CONFIG=0x08） |
| 加速度量程 | ±4 g（ACCEL_CONFIG=0x08） |
| 寄存器地址 | 8 位 |

## API

```cpp
modules::Mpu6050 imu;
std::uint8_t id = 0;
Error e = imu.probe(board_i2c(), id);   // 读 WHO_AM_I
e = imu.init(board_i2c());             // 校验 ID + 写配置
modules::Mpu6050Raw raw;
e = imu.readRaw(raw);                  // 14 字节原始值
modules::Mpu6050Data data;
e = imu.read(data);                    // 换算成 g / °/s / °C
```

`probe()` 只读 ID，不写配置；`init()` 会再次读 ID，确认是 `0x68`，否则返回 `Error::NotSupported`。

## 数据换算

```text
accel_g   = raw_accel   / 8192.0
gyro_dps  = raw_gyro    / 65.5
temp_C    = raw_temp    / 340.0 + 36.53
```

## 错误处理

- 未初始化：`Error::NotInitialized`
- 地址不对/不是 MPU6050：`Error::NotSupported`
- I2C NACK/总线错误：`Error::Hardware`
- I2C 超时：`Error::Timeout`
- 参数为空：`Error::InvalidArgument`

## 接线

| MPU6050 | F103 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL | PB6 |
| SDA | PB7 |
| AD0 | GND（地址 0x68） |
| INT | 不接 |

模块一般自带 4.7 kΩ 上拉；若读不到 ID，先查 SCL/SDA 是否接反、AD0 是否接地、上拉是否存在。
